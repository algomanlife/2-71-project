# CUDA Research Laboratory (research/cuda-lab)

Standalone synthetic CUDA benchmark suite for NVIDIA Blackwell (sm_120)
performance characterization. **Independent of the project's search
application** — no wallet targets, no private-key search, no address
matching. All inputs are deterministic public constants; all outputs are
verified against public test vectors generated by the independent python
`ecdsa` library.

**Status:** compiles in CI (CUDA 13, sm_120); runtime measurements
pending execution on the RTX 5090 rig (see `scripts/run_experiments.py`).

## Build & run

```bash
cd research/cuda-lab
cmake -B build -DCMAKE_CUDA_ARCHITECTURES=120 && cmake --build build -j
./build/cuda-lab-tests                 # correctness (public vectors)
./build/cuda-lab-bench --list          # benchmark catalog
./build/cuda-lab-bench --bench modmul256 --reps 5
python3 scripts/run_experiments.py --reps 5          # full suite -> results/
python3 scripts/run_experiments.py --compare results/<base>.json results/<cand>.json
```

## Benchmark catalog — precise unit of work ("op")

| Name | One op is… | Metric |
|---|---|---|
| `int32-mix` | one iteration of `v = (v + 0x9E3779B9u) ^ rotr(v,13)` (u32) | Gops/s |
| `int32-mul` | one iteration of `v = v * 0x85EBCA6Bu ^ rotr(v,11)` (u32) | Gops/s |
| `int64-mul` | one iteration of `v = v * 0x9E3779B185EBCA87 ^ (v>>23)` (u64) | Gops/s |
| `modmul256` | one secp256k1 256-bit modular multiplication (`_ModMult`, project arithmetic extracted verbatim to `include/lab/secp_ref.cuh`) | Gops/s |
| `global-rw` | one coalesced 64-bit global load + one 64-bit global store (16 B) | GB/s |
| `local-rw` | one 64-bit local-memory load + store on a 512 B/thread dynamically-indexed array (the `subp[]` access class) | Gops/s |
| `divergent` | one warp-divergent iteration (odd lanes: mul; even lanes: add) | Gops/s |
| `ec-scalar-mul` | one full affine scalar multiplication k·G (public scalar; one field inversion per point op — the project's setup-phase cost class) | Mops/s |
| `launch-latency` | one empty kernel launch | µs/launch |

**The 10-Gops research target** is defined on `modmul256`: sustained
≥ 10·10⁹ secp256k1 modular multiplications per second on the RTX 5090,
measured as the median of ≥ 5 repetitions with variance recorded. This
metric is **synthetic-workload throughput only** — it is never Bitcoin
key-search throughput and never elliptic-curve-operations-per-second of
the search pipeline (different workloads, never mixed in reports).

## Validity verification (Phase 3)

`--verify` / `--verify-only`: every benchmark kernel is re-run with its
final per-thread value written unconditionally and cross-checked against
an exact **host reference** of the same arithmetic — bit-for-bit, all
verification threads. Agreement proves the timed iterations actually
executed (DCE / loop elision / empty timing would diverge). The
experiment runner refuses to time any bench that fails verification, and
every record carries `verified: true/false`. Audit of the first reported
measurements: `docs/research/BENCHMARK_VALIDATION.md`.

## Correctness

`tests/test_vectors.cu` (ctest `public_vectors`): chained modmul vs
public vectors (A·B, A·B⁸, A·B⁶⁴ mod p) and affine scalar multiplication
vs public points (2G, 3G, 7G, k·G for a public constant k). Vectors in
`include/lab/vectors.h`, generated with python `ecdsa`.

## Layout

```

├── README.md            this file

├── include/lab/         kernels.cuh (op definitions), vectors.h, secp_ref.cuh

└── reports/             generated markdown summaries
```

## Rules

1. A single measurement is never a result: medians of ≥ 5 reps with
   variance, via `scripts/run_experiments.py`.
2. Records in `results/` are append-only; corrections add new records.
3. Synthetic ops/s, EC ops/s, and key-search Mkeys/s are never mixed or
   compared directly.
4. The wallet-target search pipeline is never modified for lab work.
